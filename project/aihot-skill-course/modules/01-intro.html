这是什么：让 AI 助手替你「刷」AI 资讯

一句话问出去，一份中文 AI 简报回来——中间发生了什么？

先说结论：两个东西，一个名字

这个项目叫 aihot，但它其实是两层东西叠在一起——很多人会搞混，先拆清楚：

🌐
AI HOT 网站（aihot.virxact.com）

一个公开网站，每天自动收录、翻译、摘要全网 AI 资讯。它是数据源——资讯住在那里。

📜
aihot 这个 Skill（就是 SKILL.md 这份文档）

一份教 AI 助手「怎么去那个网站拿数据、怎么翻译成人话」的说明书。它是中间人——本身不含任何资讯。

💡
关键区分

整个项目其实只有一个文件：SKILL.md。它不是 App、不是后端、没有数据库——它是一份写给 AI 看的说明书。网站是别人的，这个 Skill 只是教你的 AI 助手「怎么开口问那个网站要数据」。

「Skill」是个啥？为什么能教 AI 新本事

你可能在 Claude Code、Cursor、Codex 这些工具里见过「Skill」这个词。说人话：它就是一张塞进 AI 口袋的便签。

AI 助手本身是个聪明但什么都「大致知道一点」的通才。它不会知道：aihot 这个网站存在、它的 API 长什么样、为什么 curl 会被挡、日报和精选有什么区别。这些「这里特有的规矩」就写在这张便签上。AI 一旦读到了，就临时拥有了这个能力。

🧠
「Skill」这个词的两种读法

读作「技能」：它是 AI 助手的一种扩展机制——一份按约定格式写的 markdown 文件，平台发现它、在合适时机把它喂给 AI。读作「这个项目本身」：aihot 这个 Skill 特指 /aihot/SKILL.md 这一份文档。这节课讲的是后者。

这一趟旅程的本质

AI 助手自己没有今天的新闻——它的训练数据是过去的、静态的。它真正干的活是「会读说明书 + 会发网络请求 + 会排版」。把过时记忆当今日新闻讲，是这个课程要帮你识别并拒绝的头号 AI 翻车模式。

这张「便签」长什么样

SKILL.md 的开头是这么几行——左边是它的真身，右边是说人话版本。注意那个 YAML frontmatter，它是整份文档的「身份证」。

SKILL.md 真身 
---
name: aihot
description: AI HOT 中文 AI 资讯查询 Skill。
  当用户想知道今天 AI 圈有什么、AI 日报、
  AI 热点、最近 OpenAI/Anthropic/Google 发布了
  什么...时使用。Skill 会直接 curl 公开 REST API
  拉数据并整理成中文 markdown 简报...
---
说人话

三减号是开关：从这里到下一个三减号之间，是给平台看的元信息，不是给人读的正文。

name：这个技能叫 aihot——平台靠它建索引、做去重。

description：这段才是灵魂。它告诉 AI「什么时候该把我掏出来用」——列了一大堆触发词（AI 日报、AI 热点、最近 OpenAI…）。

末尾那句「会直接 curl 公开 REST API」是给 AI 的能力预告：别瞎编，去查实时数据。

⚠️
description 写得好不好，决定这个 Skill 会不会「睡大觉」

AI 是靠语义匹配 description 来决定要不要用这个 Skill 的。SKILL.md 里特意写了一句「不要 undertrigger」——意思是触发词列得不够全，AI 就会在该用时不用，转而拿过时记忆糊弄你。这正是「便签写得清楚」比「便签写得简短」更重要的原因。
