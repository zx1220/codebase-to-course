你以为它是个能跑起来的软件?错了。3300 多个文件里,绝大多数是 Markdown 文档——是写给 AI 读的说明书,教它怎么规划、怎么测试、怎么查安全。

SOUL.md 
# Soul

## Core Identity
Everything Claude Code (ECC) is a production-ready AI coding plugin with 30 specialized agents, 135 skills, 60 commands, and automated hook workflows for software development.

## Core Principles
1. **Agent-First** — route work to the right specialist as early as possible.
2. **Test-Driven** — write or refresh tests before trusting implementation changes.
3. **Security-First** — validate inputs, protect secrets, and keep safe defaults.
4. **Immutability** — prefer explicit state transitions over mutation.
5. **Plan Before Execute** — complex changes should be broken into deliberate phases.
逐句中文

# Soul —— 整个项目的「身份证」。这一行是 一级标题,宣告这份文件定义 ECC 是什么。

## Core Identity —— 核心身份。下面一句话自我介绍,是整个项目最重要的那句话。

ECC 是一个「生产级」AI 编程 插件:配了 30 个专家、135 个技能、60 个命令,还有自动化的 hook 工作流。

## Core Principles —— 五条「铁律」,教 AI 该怎么干活。

Agent-First:尽早把活儿交给对的专家(对应 hero 动画里的接力)。

Test-Driven:先写/更新测试,再相信改动。

Security-First:校验输入、保护密钥、保持安全默认。

Immutability:改状态时用「显式切换」而非偷偷改一个变量——避免难以追踪的副作用。

Plan Before Execute:复杂改动要先拆成清晰的阶段,而不是上来就写。

💡
这就是整个项目的灵魂

ECC 不是代码库,是一摞「写给 AI 的说明书」。AI 读了这些说明书,才知道该规划、该测、该查安全。理解了这一点,你就理解了整个项目——剩下的全是细节。

如果你还不信「这是个文档项目」——看看它真实的文件构成。绝大多数是给 AI 看的说明书,而不是能跑的程序。

这意味着

.md 占了 75% —— 这就是「写给 AI 的说明书」。每多一份,裸 AI 就多懂一点规矩。

.js 只有 405 个 —— 这些是真正「跑起来」的代码,负责安装和执行 hook。

.py 才 62 个 —— 几乎只为一个仪表盘服务,给人类看 AI 干活的统计。

所以这个项目的主要产出物,是文字,不是程序。读它的最佳方式,就是读说明书。

那这些说明书都教 AI 什么?看一眼 RULES.md 里的「铁律」:

RULES.md 节选 
## Must Always
- Delegate to specialized agents for domain tasks.
- Write tests before implementation and verify critical paths.
- Validate inputs and keep security checks intact.

## Must Never
- Include sensitive data such as API keys, tokens, secrets.
- Submit untested changes.
- Bypass security checks or validation hooks.
规矩翻成大白话

必须做:把专业活儿交给专家 agent;写实现前先写测试;始终校验输入。

绝不能做:别把 API key、token、密钥写进代码;别提交没测过的改动;别绕过安全检查。

看明白了吗——它不在教 AI 怎么写代码,而在教它「什么该做、什么绝不能做」。这就是说明书的力量。
