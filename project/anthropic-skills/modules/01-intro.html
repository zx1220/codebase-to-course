什么是 Skill？

你每天都在用 AI 做事——但你有没有想过，能不能给它装一个"专门技能"？

先想一个场景

想象一下：你让 AI 帮你处理一个 Excel 表格。可它根本不懂你们公司那一套特殊的"利润率要按蓝色、年份不带千位分隔符"的规矩。每次都要重新解释一遍，对吧？

如果能一次性把这些规矩教会它，以后它每次碰到表格都自动照办——那该多省心。

💡
这就是 Skill 想解决的问题

Skill 是一个装满说明书、脚本和资源的文件夹，让 Claude（以及其他 AI）在碰到特定任务时"自动加载"这些知识，不用你每次重复啰嗦。

提示：文中的 虚线词语 都可以悬停/点击查看大白话解释。

用最直白的话说

官方的定义是这样写的：

README.md 

Skills are folders of instructions,
scripts, and resources that Claude
loads dynamically to improve performance
on specialized tasks.
大白话翻译

Skill 就是一个装着说明书的文件夹……

里面还可能有脚本（能直接运行的代码）和各种资源（比如模板、字体）……

Claude 会根据需要动态加载它——用到时才翻开，不用时收起来。

目的只有一个：让它在某个专业任务上做得更好、更稳定。

🎯
打一个比方：技能包

想象 Claude 是个聪明的实习生。它什么都能学，但你没教过的规矩它就不知道。一个 Skill 就像是你递给它的一份"岗位手册"——只在这个岗位需要时才拿出来看，平时不占它脑子。

一个真实的 Skill 长什么样？

这个仓库里就有 17 个现成的 Skill。咱们挑一个最直观的看看它的"身份证"——也就是它最核心的那个文件 SKILL.md：

下面这段是 YAML 写的"配置区"，夹在两组三道杠 --- 中间：

skills/pdf/SKILL.md 

---
name: pdf
description: Use this skill whenever the
  user wants to do anything with PDF
  files. This includes reading or
  extracting text...
---

# PDF 处理指南
（后面是详细的操作步骤）
逐行翻译

这三道杠 --- 是一个分隔标记，告诉 AI "上面这部分是配置信息"。

name：这个技能叫 pdf，是它的唯一名字。

description：这段话才是真正的"触发开关"——它告诉 Claude 什么时候该用这个技能。

意思是："只要用户想对 PDF 文件做任何事，就用我。"

第二个 --- 表示配置结束。

下面就是真正的"教学内容"了。

就这么简单。一个文件夹、一个 SKILL.md 文件，就是一个完整的 Skill。

它到底解决什么问题？

本质上是两个矛盾：

🧠

矛盾一：AI 的脑容量有限

你没法把世界上所有的规矩一次性塞进对话里。AI 每次"记不住"那么长的上下文。

🔄

矛盾二：你不想重复劳动

每次开新对话都要重新解释一遍"我们公司表格怎么排版"，太累，还容易出错。

Skill 的解法是"按需加载"：

  • ✅ 把专业知识打包进文件夹，一次写好
  • ✅ AI 平时只看它的名字和简介（省脑容量）
  • ✅ 真要用到了，自动翻开详细说明
  • ✅ 用完就收起来，不干扰其他任务

关键洞察

Claude 自己决定要不要用某个 Skill——你不需要手动"调用"。它靠的就是那个 description 字段。写得好，它就准；写得差，它就漏。这就是为什么后面我们会专门讲怎么写好这个字段。
